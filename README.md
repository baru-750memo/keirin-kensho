## 起動

このフォルダの「プレビューを開く.cmd」で起動できます。現在のURLは http://127.0.0.1:3110/ 。

開発: `npm run dev`
本番形式: `npm run build` → `npm start`
別PC: Node.js 24を用意し `npm ci` を実行してから上記コマンド。
検査: `npm run check`、起動中に `node scripts/check-http.mjs`。

Next.js 16.3.4 / React / TypeScript。依存バージョンはpackage-lock.jsonに固定。CMS・DB・外部認証は不要です。Windowsの制限付き実行環境ではビルド/localhost接続に追加の実行許可が必要になる場合があります。

## データ更新

`data/feed.json`: v1.0から継承した17件。id / kind / category / title / summary / url / publishedAt / checkedAt / sourceClass / statusを管理。
`lib/content.ts`: 編集記事、検証記事、3社の名称、検索処理。新記事は重複しないslugと出典・本文・画像説明を登録。
`data/editorial.json`: 競輪場・歴史・検証方法・公式操作図の4記事。evidenceで証拠画像、correctionsで訂正前後と理由、metricsで期間・件数・費用・払戻・集計根拠を管理できます。実購入データがないため実績値は登録していません。
`npm run build` はデータ検査を先に実行します。画像不足、重複ID、不正な出典URLなどを検出するとビルドを止めます。

状態はdraft（資料前）、review（再確認待ち）、reviewed（内容照合済み）。変更後に `npm run check` とビルドを実行してください。reviewedは掲載内容の照合状態であり、サービスの推奨や成績保証ではありません。ニュースの日付は発表日、checkedAtは資料確認日です。

RIDEXのトップ・FAQの登録案内の違いと公開料金表、競輪祭の公式発表、公式ガイドを11月20日に確認。継承した16件の収集資料は今回再照合していないためreviewです。2027年度施策の記事は11月18日の既存確認記録を継承しています。

## 公開設定と残事項

既定は全ページnoindex、robotsでクロール抑止、サイトマップ空。canonicalは仮のlocalhostです。これはアクセス認証ではありません。

`.env.example`を参照し、正式ドメイン・運営者・訂正窓口を設定します。SITE_PUBLISHED=trueで再ビルドすると、reviewed記事だけを一覧・検索・記事ルート・サイトマップに出力します。必須設定不足や不正URLでは明示的に失敗します。設定変更だけでデプロイは行いません。

公開前に残るもの: 正式名称、ドメイン、運営者、窓口、素材の利用範囲、紹介・広告関係。LINEと紹介パラメータは有効化していません。v1.0の候補リンクは外部公開の承認として扱わず、RIDEX公式の原文リンクのみ検証根拠として掲載しています。

SHIVA・NEROの一次資料、実購入の全参加履歴、各社の個別プラン評価は未完了。未確認値を架空の料金・順位・回収率で埋めていません。ニュース自動収集・管理画面・自動公開はありません。記事追加はファイル編集と再ビルドです。
